# 王浩 Paulus · 项目展示网页

项目展示仓库，用于面试演示与个人版本管理。

在线演示：https://paulussamvel-lang.github.io/paulus-project-showcase/

## 展示内容

- 提示词工坊：页内运行实际工具，可选择示例、切换模型、编辑输出。
- 大字提词器：默认全宽网页界面，内置最新版标点断句与长句切分，可编辑和滚动阅读。
- 下载识别修复：示例地址的识别顺序对照，以及单条作品和列表下载的真实截图。

网页还提供讲稿、约10分钟的时间安排、计时、全屏和图片放大。

## 本地运行

安装 Node.js 18 或更新版本。在项目目录运行：

```sh
npm start
```

打开 http://127.0.0.1:4173 。项目没有第三方 npm 依赖，无需安装依赖或构建。
