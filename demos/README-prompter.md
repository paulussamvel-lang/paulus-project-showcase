# 大字提词器

把文稿放大，在 iPad、手机或电脑上用手指上下拖动阅读。阅读时先按逗号、句号、分号、冒号、问号、感叹号、顿号、破折号（包括 --）等标点断句。短句一句一行，超过 10 个字的长句再切分。保留原文段落和空行。行末剩余的句号、逗号等标点会接在上一行，避免标点单独占一行。

## 使用

1. 下载 [prompter.html](https://raw.githubusercontent.com/paulussamvel-lang/chinese-teleprompter/main/prompter.html)，用浏览器打开。
2. 粘贴文稿，点击「放大阅读」。
3. 上下拖动页面，自己掌握阅读速度。电脑也可以用滚轮、触控板或浏览器默认方向键滚动。
4. 点击「编辑文稿」修改内容。「返回阅读」可回到原来的阅读位置。

这是一个纯手动的大字阅读工具。字号在平板和电脑上为 48px，窄屏手机上会缩小以容纳一行内容。源码集中在一个 HTML 文件中，无需安装依赖或配置服务器，下载后可离线使用。
